# 下一阶段：让首个真实攻略完整可用

评估日期：2026-11-22（Asia/Shanghai）。当前实现与 [实施记录](implementation-status.md) 配套；本文是下一阶段计划，不表示下面的功能或内容已发布。

## 当前判断

站点已经具备英日页面、搜索、个人探索清单、自定义素材表、图片展示和 GitHub → Cloudflare Pages 自动发布。现有 5 张游戏配图覆盖首页、案件/探索入口、指南索引和上线准备文章；英文 logo 已接入共享页头与页脚。首页暂不需要继续增加装饰性图片。

当前只有 4 篇英语指南与 4 篇对应日语指南，主题主要是发售准备和本站工具的使用。案件仍是原创交互练习，探索没有已核验的路线，角色页没有正式养成数据，素材规划器需要手输需求。下一阶段的核心目标是完成首个有资料依据的真实攻略，而不是扩大空页面数量。

## 图片准备顺序

| 顺序 | 图片 | 建议规格 | 放置与验收 |
| --- | --- | --- | --- |
| 1 | 英日社交分享封面 | 各 1200 × 630；JPEG/PNG；包含 Silver Palace Guide 和非官方身份 | 为 `og:image`、Twitter 卡片提供默认图。当前模板尚无分享图片元数据；不能将主视觉已存在视为分享封面已完成 |
| 2 | 首个真实案件的资料截图 | 原始截图建议宽 ≥ 1600px；按内容取 3–5 张 | 覆盖任务前置、卡点和关键线索；答案图放在对应提示层内，列表只用安全预览图；每图记录版本、来源、说明和剧透级别 |
| 3 | 首条探索攻略的定位与步骤图 | 1 张定位图及 3–6 张必要步骤图；原图宽 ≥ 1600px | 标记起点、可识别地标、转向/交互点、完成确认；保留未标注原图，按路线顺序配对步骤 |
| 4 | 养成材料图标与角色头像 | 图标建议 128 × 128，头像建议 512 × 512；优先透明源图 | 只为已核验的首个角色培养区间收集，使用稳定 ID；图像与数值分别核验，不由头像推断角色名字或材料成本 |

当前英文 logo 的主体分辨率足以支持页头。透明背景或矢量版本将有利于深色背景和大幅用途，可以后续替换，不阻塞本轮。

## 开发队列与完成标准

| ID / 顺序 | 任务 | 具体交付 | 完成标准与依赖 |
| --- | --- | --- | --- |
| NEXT-01 / 优先 | 真实案件内容模型与详情模板 | 案件/阶段/线索稳定 ID、前置条件、三层提示、配图及来源、server/build/核验日期；接入案件列表和详情路由 | 先用不公开的草稿跑通结构；验证草稿不生成路由、同篇英日可切换、切换阶段收起提示、答案与剧透图不进入搜索摘要。发布第一篇依赖可复核的真实案件资料，不用原创练习冒充 |
| NEXT-02 / 并行上线事项 | 正式域名与分享预览验收 | 主域 HTTPS、www 跳转、canonical 与 sitemap 一致；EN/JA 分享封面与元数据 | 默认 Pages 地址已工作。2026-11-22 只读请求中主域超时、www 连接失败；需要单独检查 DNS/绑定/证书，不能凭超时确定具体故障。此前 DNS 替换仍有待确认，本轮未修改 |
| NEXT-03 / 随后 | 首条探索路线详情与关联清单 | 区域、前置、步骤图、可复现路线、完成条件；从攻略把条目加入个人清单 | 固定条目 ID，避免重复添加；刷新及英日切换进度一致；保留用户自建笔记和原备份。发布依赖已核验路线 |
| NEXT-04 / 随后 | 首个角色的材料区间预设 | 独立的材料与角色数据、区间选择、需求自动填入、来源/版本提示 | 先支持一个完整培养区间；缺失数据明确显示不可计算，不能当作 0；选择区间后与手算一致，旧自定义表仍能使用。依赖完整成本记录 |
| NEXT-05 / 持续 | 来源和翻译更新提示 | 原文修订与译文修订比较、核验信息、更新后待复查提示 | 英语更新后能识别日语尚未同步；发布检查覆盖图片引用、来源、译文状态和已核验数据 |

**建议下一次开发从 NEXT-01 开始。** 首个真实案件可以同时验证内容模型、分级提示、图片剧透边界、英日对应和搜索收录，能让现有站点特色形成完整体验。缺少实测资料时，继续完成草稿模型与模板；公开内容保持当前范围。

暂缓账号、跨设备云同步、互动地图、第三语言与批量角色排行，先确保首个案件、探索路线和材料区间可用且可维护。

## 本轮范围

本轮仅接入新英文 logo、记录图片缺口与上述开发计划，并沿用 GitHub 触发 Pages 发布。NEXT-01–05 没有在本轮批量实施；不修改 DNS 或增加账户/统计服务。
