## 资料依据与取舍

- 重新阅读了此前保留的第一方英日人物介绍、发行新闻稿和7月战斗资料。事实来源台账仍是 **2026-11-22 的确认记录**，文章编辑日期为11月24日，二者分别显示。
- 本轮直接请求当前官方人物页成功取得页面外壳，但其应用模块下载在25秒内未完成，不能据此宣称已重核当前全部人物正文。因此没有将来源日期批量改成11月24日。
- Lorin 的原介绍除已有简述外，还提供组织处境、合作背景、个人与制度的对照、两种语言的人物描写。本批将这些内容独立整理为试点。
- Alf、Argos 的可用介绍较短，本批保留在目录和比较工具，未为达到3篇数量而复制卡片扩页。Cynthia II、Firtho、Gratia 继续沿用已有定性装备资料。
- 7月战斗资料确认 Reactor 属性与共振效果的关系；Alf 人物介绍确认背部 Reactor 能切换武器，但没有建立“共振满槽触发该切换”的共同规则。
- 活动规则只支持 The Curiosity Mystery 的名称、4星 Motive 类型及抽选条目数量，不能补全装备槽、适配人物、属性和养成规则。本批补现有指南，不生成 `equipment-and-resonance/` 独立页。
- 仍没有足以公开的完整真实案件、复现路线或完整素材区间。本批不发布示例数据为实测内容，也不把空白模板算作已交付攻略。
- Fandom 竞品页面在此前研究中未成功读取，本批没有追加关于其栏目、内容量或流量的未经核实结论。

## 兼容与内容校验

- `character-details.json` 只保存具备完整官方背景的详情，严格区分定性人物资料与数值育成预设。英日文本放在同一修订中；校验要求对应人物存在、来源来自该人物的官方台账、章节 ID 唯一、文章更新不早于来源确认。
- 只为有详情的 Lorin 生成独立路由。共享链接函数供目录、比较、术语和素材规划器使用；其余19个角色继续定位原目录锚点。
- 原20个目录卡片 ID、角色比较参数和素材规划器的角色参数保持有效。更改参考链接不改素材存档结构、数量或任何预设。
- 初心者指南英语修订升到3，日语修订升到2并同步英语来源修订3；战斗指南英日修订均升到3，继续保留上批添加的旧锚点。
- 构建检查新增详情路由白名单、目录/工具入口、目录目标、语言对应和 sitemap 校验。通用内部资源、canonical、CSP、草稿隔离检查继续执行。

## 验证结果

- `npm run check`：72个文件，0错误、0警告、0提示。
- `npm test`：40项通过。新增3项覆盖人物详情资格/来源/章节、双语与数值字段隔离、详情链接及旧目录锚点回退。
- `npm run build`：50个HTML页面；Pagefind收录46页、2种语言。内容、双语修订、内部链接、canonical、hreflang、sitemap和私有资料隔离检查通过。
- 浏览器：总览 → Lorin → 比较 Lorin/Rex → 素材规划器可以连续使用；比较参数为 `a=lorin&b=rex`，规划器参数为 `character=lorin`。
- 更换参考角色到Alf时链接回到旧目录锚点，切回Lorin时进入详情。英日切换保留角色参数。原有素材记录120/35以及缺口85保持不变。
- 总览、人物详情和战斗指南的英日6个代表页分别在320px、390px检查：实际内容宽与滚动宽为305/305、375/375；表格无横向溢出。桌面人物详情完成视觉检查。
- 英语搜索 `Lorin`、日语搜索 `ローレン` 均出现本语言的人物详情与游戏总览，以及章节结果；未混入另一种语言的页面。测试标签页未捕获控制台错误。

这是本地构建和站内搜索的验收记录，不代表生产发布、Google收录或排名变化。上线后再执行部署检查；Google效果需取得Search Console数据后观察。
