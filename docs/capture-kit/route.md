# 探索路线采集记录

此表是采集模板，未知项留空。沿用现有路线模型和稳定 ID；不要依据人物插画推断地点。

在同包 `content.json` 填写英日有序步骤；每步关联 `assets/` 的脱敏截图，并登记 `evidence.csv`。原始资料留在 `originals/`。复现与双语审核后使用 `capture:check` / `capture:prepare`，不直接发布本记录表。

- 安全定位图文件：
