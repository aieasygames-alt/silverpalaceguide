## 首轮范围调整

当前来源能支持官方发行信息，不能支持完整的角色养成数值或游戏内案件步骤。因此：

1. 素材工具先开放自定义需求表，不预置角色、等级或掉落数值。
2. 探索清单保存用户自己的记录，不声称覆盖全收集。
3. 事件页用原创练习验证交互，尚不提供真实案件攻略。
4. 角色资料页明确说明研究状态，排除搜索索引和 sitemap。

这是第一阶段可审阅的功能基线。原方案中的自动角色区间规划与真实案件/探索攻略，在取得可核验数据后继续接入。
