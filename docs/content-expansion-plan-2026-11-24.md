## 2. 内容方向

目标是让读者能够从“认识游戏或角色”走到“理解机制”，再走到“完成案件、找到路线、计算材料”。资料内容建立清楚的主题入口，实测内容与现有工具形成可复查的操作闭环。

沿用两条资料供给路径：

1. 官方资料路径：游戏总览、人物资料、机制说明、地区背景、活动与更新说明。每次扩展先重查第一方资料，明确测试版、正式版和未来计划。
2. 实测路径：真实案件 → 探索路线 → 完整材料区间。继续使用已有采集、复现、翻译和发布门槛，不因扩展资料页而取消或后移这三个里程碑。

搜索词示例仅表示读者可能提出的问题，不代表已经取得搜索量或热门度数据。取得 Search Console 数据后再调整主题顺序。

## 4. 第一批具体选题

### A. 游戏总览，1 个主题、英日两版

候选标题：`What is Silver Palace? Gameplay, characters and investigations` / `白銀の城とは？探索・戦闘・推理の基本紹介`。

独立价值：回答“这是什么游戏、核心内容如何联系”，与现有 beginner guide 的“先读哪篇、先确认什么”分工。它不是发行/下载问答的复制页，也不代替官网。

内容组成：官方可确认的游戏概况、调查/探索/战斗的关系、人物资料入口、测试与正式版范围、发行和平台指南入口。不能确认的商业模式、联机规则或其他字段不设装饰性的空表。

### B. 角色详情试点，最多 3 个角色

优先研究候选：Alf / フウ、Argos / アーガス、Lorin / ローレン。理由是现有数据对三者都具备背景与定性装备/战斗信息，而非已确认它们搜索量最高。其他同等条件候选为 Cynthia II、Firtho、Gratia。

拟用路径：`/{locale}/characters/{id}/`。保留现有稳定 ID、目录锚点和比较工具参数，目录卡片增加“阅读完整资料”入口，术语搜索和比较结果指向相关详情。

每页应有：官方英日名及称号、独立整理的人物背景、已公布的装备与定性说明、相关机制的解释和链接、来源及版本、明确的剧情披露范围。技能和成本在取得证据后再接入，不能把“资料页”命名为已经完成的 build guide。

发布门槛看新增信息和独立用途，不用凑字数或满屏“未知”填充。若原始资料不足以超出现有卡片，就继续完善目录，不为达成 3 页目标硬拆。

### C. 装备/机制关系核验，先研究再决定是否建页

针对 Reactor、共振与 Motive 建立逐条事实清单：来源是否定义了它、它与角色/装备/活动道具是什么关系、是否属于测试资料、数值是否公开。只有关系得到证实且需要完整说明时，才创建 `/{locale}/guides/equipment-and-resonance/`；否则补进原战斗指南和术语库。

### D. 首组实测内容，沿用既有队列

The Resurrection Mystery 已在官方推理介绍中出现，可列为采集候选；不能仅凭名称和预告就认定它是第一篇可发布案件。以实际拿到的完整记录决定首篇。

完成案件后接一条实测路线，再接一个完整材料区间。实测条目、截图、稳定 ID 与存档约束见 [内容流程](content-workflow.md)，不重建同类模板或通用笔记工具。

角色资料仍使用官方定性数据与实测数值数据分离的模型，不为角色详情绕过 `characters.json` 的玩法发布门槛。道具总览将来接入时，共享稳定道具 ID 和来源，避免与材料成本数据各维护一份名称；活动条目 ID 继续表示独立抽选栏位，不因新增物品页更改旧存档含义。

内链围绕任务：角色 → 相关机制 → 有证据的配装/材料 → 规划器；地区背景 → 实测路线 → 个人清单；案件机制 → 对应案件 → 分级提示。所有角色简介、工具和指南不必机械地彼此链接，只连接能帮助读者下一步判断的内容。

## 6. 分阶段执行

工期为资料可得、单人开发和编辑配合的工作量估算，不是自动执行日程；等待官方新信息、实测或翻译校对的时间另计。

## 7. 发布与效果验收

每批内容完成双语、来源、版本和剧透审核，以及项目要求的 `npm run check`、`npm test`、`npm run build`。有界面变更时检查手机排版、键盘操作、相关跳转和站内搜索；发布后运行已有部署检查。检查范围按变化确定，不为纯规划文件重复构建全站。

新页面必须与实际语言对应关系一致，进入合适的目录、Pagefind 与 sitemap，canonical 正确，草稿不泄露。角色资料中的来源和图像必须可追溯，公开页面只展示有事实依据和读者用途的内容。

## 8. 竞品补查表与暂缓项

竞品恢复可访问后，抽样记录：首页/游戏介绍、一个资料完整角色、一个资料较少角色、一个系统或物品、一个地区或任务。每条保留 URL、观察日期、已见到的信息、引用来源、本站差异和可执行动作。页面样本没有覆盖到的栏目写“未核实”，不写“竞品没有”。

只借鉴分类和满足问题的方法。事实回查官方或实测；若使用社区原创材料，需要检查相应许可、署名和使用条件，不复制竞品的文章、截图及数据库作为本站原创。

暂缓：批量拆分 20 个角色短介绍、每个术语单独建页、无官方兑换码的空代码页、没有测试标准的强度榜、无坐标依据的互动地图、用于装饰的社交帖子流。先交付总览和有内容的角色试点，同时保持真实案件 → 路线 → 材料区间的主里程碑顺序。
